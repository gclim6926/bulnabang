# 🔥🦋 불나방 (BulNaBang)

> 주식 예측의 신

## 배경

불나방은 다양한 입력 지표를 기반으로 출력 지표를 예측하는 AI 시스템입니다.

## 목표

- 여러 가지 잠재적인 **입력 지표**를 기반으로 **출력 지표**를 예측
- 매일 100점을 받는 것이 최종 목표

## 동작 설명

1. 과거의 다양한 지표들을 입력받음
2. 매일 새로운 데이터를 업데이트 받음
3. 그날의 출력 지표를 예측
4. 예측한 출력 지표와 실제 출력 지표를 비교

## 평가 방법

| 예측 정확도 | 점수 계산 |
|------------|----------|
| 100% 정확 | 100점 (만점) |
| 1% 오차 | 100 - (1 × 10) = 90점 |
| N% 오차 | 100 - (N × 10) 점 |

**목표: 매일 100점 달성**

## 지표 관리

### 입력 지표
- 유동적으로 추가/삭제 가능 (Frontend에서 관리)
- API를 통해 매일 자동 수집 또는 CSV 업로드

### 출력 지표
- 유동적으로 추가/삭제 가능 (Frontend에서 관리)
- API를 통해 매일 자동 수집 또는 CSV 업로드

## 프로젝트 구조

```
불나방/
├── backend/          # FastAPI 서버
│   ├── data/         # 데이터 저장소
│   ├── models/       # 예측 모델
│   ├── services/     # 비즈니스 로직
│   └── api/          # API 엔드포인트
│
└── frontend/         # React 앱
    ├── components/   # UI 컴포넌트
    └── pages/        # 페이지
```

## 시작하기

```bash
# Backend
cd backend
pip install -r requirements.txt
python main.py

# Frontend
cd frontend
npm install
npm run dev
```
